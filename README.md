# Hub Logístico

Simulador 3D de un centro de distribución para la carrera de Ingeniería en Logística (UTEC).

- **Usar en línea:** https://ric20527.github.io/hub-logistico-web/
- **Usar sin internet:** descargar [`hub-logistico-sin-internet.html`](hub-logistico-sin-internet.html) y abrirlo con doble clic (Chrome, Edge o Firefox).

Este repositorio contiene solo la versión publicada. Se actualiza automáticamente desde el proyecto del hub con `npm run publicar`, así que no se edita a mano.
